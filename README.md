# AutoDiag

Android-first automotive diagnostics application.

## Current status
- Initial Kotlin + Jetpack Compose project structure
- Dark diagnostic dashboard
- Virtual/demo mode switch
- Overview, connection, live-data and more screens
- Placeholder telemetry is explicitly marked as demo data

## Planned
1. OBD-II transport layer (Bluetooth Classic, BLE and Wi-Fi)
2. ELM327 command/session implementation
3. DTC read/clear and freeze-frame support
4. Live PID polling and charts
5. Vehicle/module coverage with capability checks
6. Simulator test scenarios
7. Localization (Russian, Georgian, German, English)

## Build
Open the repository in Android Studio with Android SDK 35 and JDK 17.
